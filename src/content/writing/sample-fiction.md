This is a stand-in for a story, not a story. It is set the way fiction will be set in this room, so that the page can be judged before there is anything to put on it.

Stories are set with the first line of each paragraph indented and no gaps between paragraphs, the way a printed book does it. That keeps a long run of dialogue or short paragraphs from breaking the page into pieces.

The opening paragraph is not indented, and it begins a little larger. After a break in the text the next paragraph starts flush again.

---

A break like the one above is made with a line of three dashes. Use it for a change of scene, a jump in time, or a change of voice.

To replace this text, open `src/content/writing/sample-fiction.md`, keep the lines at the very top, change the title, and write the story underneath. If it is long, the reading mode in the corner of the page clears everything else off the screen.
