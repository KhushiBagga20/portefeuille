# Artwork files

Put the image files for the art gallery in this folder (PNG, JPG, WebP, AVIF or GIF),
then list each one in `src/data/art.ts` with `file: 'the-file-name.jpg'`.

The site reads each image's size by itself and makes smaller copies for the wall, so
export at whatever size you have — around 2000px on the long side is plenty.
